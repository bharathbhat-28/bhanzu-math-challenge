# Bhanzu Pre-Demo Math Challenge

A working prototype for the Bhanzu Growth PM take-home assignment.

## Purpose

A child-facing micro-experience designed to maintain engagement and anticipation between demo booking and the live Bhanzu demo.

## Experience

- 10-question math challenge
- 10-minute timer
- Instant feedback
- Score at the end
- Connects the challenge to the upcoming Bhanzu demo

## Live Prototype

[Try the prototype](YOUR-VERCEL-URL)

## Prototype Scope

This is a frontend prototype. No login, backend, database, or WhatsApp integration is required.

The intended journey is:

**Demo booked → Child receives challenge → Completes challenge → Sees score → Anticipates demo**

## Tech

HTML, React, Tailwind CSS
